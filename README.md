# War of the Ring — Java Client

The Java client this community has played on for over 15 years, continued from the
original source code by Sean McCarthy and Andrew Poulter.

**For players who own the physical game.** Friendly games for now.

## Download

**[Download the latest version](../../releases/latest)** — unzip and run. Java is included
(Windows, macOS Intel and Apple Silicon, Linux x64 and ARM), so there is nothing else to install.
Your old logs and saved games load exactly as before.

## What's in it

- LOME, WOME and KOME expansions working together, alone or combined
- Every special action die handled for you
- Replays: a replay bar, army stats, and "Ira mode" for watching and videos
- The Chronicle: the story of each game, written for you
- Each side's time tracked, like a chess clock
- Hand keys made and kept for you — no passwords to type or share
- Full Mac and Linux support
- Scenarios and variants: Treason of Isengard, Fate of Erebor, Smaug Lives! and more

The full list is in the client under **Help → What's New** (or the Reference window, Ctrl+/).

## Updates

The client checks here for new versions under **Help → Check for Updates**.
